## 1. ODBC, JDBC, ADBC의 개념과 차이

### ODBC란?

* 다양한 운영체제에서 여러 종류의 데이터베이스에 접근할 수 있게 해주는 표준 인터페이스
* Microsoft에서 만들었고, 주로 Windows 환경에서 많이 사용됨
* Excel, Access, Power BI 같은 프로그램이 DB에 연결할 때 자주 사용

### JDBC란?

* Java 프로그램이 데이터베이스에 접근할 수 있도록 해주는 표준 인터페이스
* Oracle에서 만들었고, Java 언어 전용
* Java 개발자가 SQL을 실행할 때 일반적으로 사용

### ADBC란?

* Apache Arrow에서 만든 데이터베이스 연결 인터페이스
* SQL 실행 결과를 빠르게 주고받기 위해 Arrow 포맷을 사용함
* Python, Java, Rust 등 여러 언어에서 사용할 수 있음
* 분석 작업처럼 많은 데이터를 빠르게 다뤄야 할 때 유리함

### 차이점 정리

| 인터페이스 | 만든 곳         | 사용하는 언어              | 특징                        |
| ----- | ------------ | -------------------- | ------------------------- |
| ODBC  | Microsoft    | 거의 모든 언어             | 오래된 범용 표준, 설정 복잡함         |
| JDBC  | Oracle       | Java                 | Java 전용, 널리 사용됨           |
| ADBC  | Apache Arrow | Python, Java, Rust 등 | 최신 기술, 고속 처리, Arrow 포맷 사용 |

## 2. Arrow 포맷이란?

* Apache Arrow는 다양한 언어와 시스템 간에 데이터를 효율적으로 공유할 수 있도록 설계된 오픈소스 프로젝트
* 이 프로젝트에서 만든 것이 바로 'Arrow 포맷'이라는 표준 메모리 구조
* Apache Software Foundation에서 관리하고 있으며, Python, Java, Rust 등 다양한 언어 라이브러리로 제공됨
* Arrow 포맷은 이 프로젝트의 핵심 기술 중 하나
* 다양한 프로그래밍 언어와 시스템 간에 데이터를 빠르게 주고받기 위한 메모리 구조
* 데이터를 열(column) 단위로 저장해서 분석과 계산이 빠름
* 빠른 전송과 계산, 낮은 메모리 사용량을 위해 설계됨

### 예시

행(row) 기반:

```json
[
  {"name": "철수", "age": 30},
  {"name": "영희", "age": 25}
]
```

열(column) 기반:

```json
{
  "name": ["철수", "영희"],
  "age": [30, 25]
}
```

## 3. Arrow 포맷과 Columnar 포맷의 차이

* Columnar 포맷은 데이터를 열 단위로 저장하는 방식이라는 개념
* Arrow 포맷은 이 columnar 포맷을 메모리에서 빠르게 사용할 수 있도록 구체화한 표준
* Arrow는 columnar 형식 중 하나이자, 실제로 쓸 수 있는 구체적인 구현체

## 4. ADBC와 Apache Arrow Flight SQL의 개념과 차이

### ADBC란?

* 클라이언트 측에서 SQL을 실행하고 결과를 처리하기 위한 인터페이스
* 다양한 DB에 연결할 수 있도록 설계됨
* 결과는 Apache Arrow 포맷으로 반환됨

### Arrow Flight SQL이란?

* 서버 측에서 SQL을 실행하고 결과를 Arrow 포맷으로 전송하는 기능
* Arrow Flight 위에 SQL 실행 기능을 확장한 프로토콜
* 클라이언트는 ADBC를 통해 Flight SQL 서버에 접속 가능

### 차이점 비교

| 항목    | ADBC                           | Arrow Flight SQL              |
| ----- | ------------------------------ | ----------------------------- |
| 역할    | SQL을 실행하는 클라이언트 인터페이스          | SQL 쿼리를 실행하고 결과를 반환하는 서버 측 기능 |
| 하는 일  | SQL 실행 요청, 결과 수신               | SQL 요청 처리, Arrow 포맷 결과 전송     |
| 전송 방식 | 내부적으로 Flight SQL, JDBC 등 사용 가능 | Arrow Flight 프로토콜 기반, gRPC 사용 |
| 관계    | 클라이언트 입장에서 SQL 실행              | 서버 입장에서 SQL 실행 처리 담당          |

- 즉, Arrow Flight SQL 은 Arrow 포맷 데이터를 전송할 수 있는 서버이고, ADBC 는 Arrow 포맷 데이터를 전송하는 API 이다.
- ADBC 는 여러 다양한 DB 에 연결될 수 있고, Arrow Fight SQL Server에 연결되어 사용 가능하다.
- 이 때, JDBC 에서 jar 드라이버 파일이 필요하듯이 flight SQL 드라이버 파일이 필요하다.
- Arrow Flight SQL 은 ADBC를 통하지 않고 gRPC 프로토콜로도 직접 연결 가능하다. (ex. FlightSqlClient)
- Arrow Flight SQL 에 바로 연결할 수 있음에도 ADBC를 쓰는 이유는, ADBC 는 Arrow Flight SQL 외에 다른 DB 에도 연결하여 사용할 수 있는 기능이기 때문이다.
- ADBC 로 PostgreSQL 에 연결하여 PostgreSQL 의 결과를 Arrow 포맷으로 받아볼 수 있다.

## 5. Apache Arrow Flight와 Flight SQL의 개념과 차이

### Arrow Flight

* Arrow 데이터를 네트워크를 통해 빠르게 전송하기 위한 프로토콜
* REST나 JDBC보다 훨씬 빠름
* gRPC라는 기술을 기반으로 만들어졌음

### Flight SQL

* Flight 위에 SQL 기능을 추가한 것
* 사용자는 SQL을 날리고, 결과는 Arrow 포맷으로 빠르게 받을 수 있음

## 6. Arrow IPC란?

| 문맥    | 뜻                                       |
| ----- | --------------------------------------- |
| 일반    | Inter-Process Communication (프로세스 간 통신) |
| Arrow | Arrow 데이터를 저장하거나 네트워크로 보낼 때 사용하는 이진 형식  |

* Arrow 데이터를 파일로 저장하거나 다른 곳으로 보낼 때 IPC 포맷 사용
* Flight에서도 내부적으로 이 형식 사용함

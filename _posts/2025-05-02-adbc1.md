## JDBC란?

* JDBC: Java Database Connectivity
* Java 프로그램에서 관계형 DB에 SQL을 실행할 수 있도록 설계된 Java 전용 인터페이스
* 다양한 DB 벤더가 제공하는 JDBC 드라이버 사용
* SQL 결과는 Java 객체로 변환되어 사용

### 예시 구조

```
[Java 애플리케이션]
        ↓
[JDBC API]
        ↓
[DBMS (예: MySQL, PostgreSQL 등)]
```

---

## ODBC란?

* ODBC: Open Database Connectivity
* 다양한 언어(특히 C/C++)에서 DB와 통신할 수 있는 범용 인터페이스
* Windows에서 주로 사용되며 Excel, Access, Power BI 같은 도구에 많이 쓰임
* 리눅스에서는 unixODBC 등으로 구현 가능하지만 설정이 복잡함

### 예시 구조

```
[어플리케이션]
        ↓
[ODBC API]
        ↓
[ODBC 드라이버]
        ↓
[DBMS]
```

---

## ADBC란?

* ADBC: Apache Arrow Database Connectivity
* 다양한 DB에 SQL을 실행하고, Arrow 포맷으로 데이터를 주고받기 위한 인터페이스
* Python, Java, Rust 등 다양한 언어에서 사용 가능
* JDBC/ODBC보다 가볍고 빠르며, 분석 작업에 적합
* Arrow Flight SQL 기반 서버 또는 기존 DB(PostgreSQL, DuckDB 등)와 연결 가능

### 구조 예시

```
[ADBC 클라이언트 (Python 등)]
        ↓ SQL 실행 API 호출
[ADBC 드라이버 (Flight, PostgreSQL 등)]
        ↓
[DB 혹은 Arrow Flight SQL 서버]
```

### Python ADBC 예제

```python
import adbc_driver_postgresql.dbapi

conn = adbc_driver_postgresql.dbapi.connect("postgresql://localhost:5432/mydb")
cur = conn.cursor()
cur.execute("SELECT id, name FROM users")
table = cur.fetch_arrow_table()
print(table.to_pandas())
```

## ODBC, JDBC, ADBC 차이점

| 구분   | 만든 곳              | 주요 언어                | 특징                              |
| ---- | ----------------- | -------------------- | ------------------------------- |
| ODBC | Microsoft         | 다양한 언어               | 범용 DB 연결 인터페이스, 주로 Windows에서 사용 |
| JDBC | Oracle (Java)     | Java                 | Java 전용 DB 연결 드라이버              |
| ADBC | Apache Arrow 프로젝트 | Python, Java, Rust 등 | Arrow 기반 고속 SQL 실행 인터페이스        |

* ODBC: 오래된 범용 인터페이스, 주로 Windows에서 BI 도구나 레거시 시스템에 사용
* JDBC: Java 전용 DB 접근용 드라이버
* ADBC: Arrow 포맷 기반으로 빠르게 SQL 실행하고 결과 받는 현대적 대안

---

## 웹에서 ODBC를 잘 안 쓰는 이유

* 리눅스 기반 서버에서 설정이 복잡함
* Node.js, Python, PHP 등에서는 각 언어에 맞는 전용 DB 클라이언트 사용이 일반적
* ODBC는 데스크탑 앱에서 더 많이 활용됨 (예: Excel, Power BI)

---

## Apache Arrow란?

* Apache Arrow: 고속 분석을 위한 컬럼 기반 메모리 포맷
* Arrow 포맷은 해당 프로젝트에서 정의한 데이터 표현 방식
* 다양한 언어 간 효율적인 데이터 공유 가능
* 컬럼 단위 데이터 구조로 빠른 연산과 압축 효율 제공

### 예시

행 기반 (row-based):

```json
[
  {"name": "철수", "age": 30},
  {"name": "영희", "age": 25}
]
```

열 기반 (columnar):

```json
{
  "name": ["철수", "영희"],
  "age": [30, 25]
}
```

---

## Columnar Format vs Arrow Format

* Columnar 포맷은 열 기반 저장 방식이라는 일반 개념
* Arrow 포맷은 그것을 구체화한 표준 구현

  * 타입, 오프셋, 널 값 등을 포함한 메모리 구조를 정의

---

## Apache Arrow Flight란?

* Arrow 데이터를 gRPC 기반으로 고속 전송하기 위한 프로토콜
* REST, JDBC 대비 빠른 전송 속도 제공
* 대용량 데이터 분석 워크플로우에 적합
* 양방향 스트리밍 가능
* 다양한 언어 지원 (Python, Java, Rust 등)

---

## ADBC vs Arrow Flight

| 항목    | ADBC               | Arrow Flight      |
| ----- | ------------------ | ----------------- |
| 역할    | SQL 실행 인터페이스       | Arrow 데이터 전송 프로토콜 |
| 목적    | SQL 실행 및 결과 수신     | 데이터를 빠르게 전송       |
| 전송 방식 | Flight, TCP 등 다양   | gRPC 기반           |
| 관계    | 내부적으로 Flight 사용 가능 | 독립적으로도 사용 가능      |

---

## Apache Arrow Flight SQL

* Arrow Flight 위에서 SQL 쿼리를 실행할 수 있도록 확장한 프로토콜
* SQL 실행 요청 및 결과 수신 가능
* 결과는 Arrow 포맷으로 전송

### 구조 예시

```text
클라이언트
  ↓ Flight SQL API
서버
  ↓ 내부적으로 PostgreSQL 등
DB
```

### Python 예제

```python
import pyarrow.flight.sql as fl

client = fl.FlightSqlClient("grpc+tcp://localhost:32010")

info = client.execute("SELECT * FROM users")
reader = client.do_get(info.endpoints[0].ticket)

table = reader.read_all()
print(table.to_pandas())
```

## IPC란?

| 문맥    | 의미                                      |
| ----- | --------------------------------------- |
| 일반    | Inter-Process Communication (프로세스 간 통신) |
| Arrow | Arrow 데이터를 저장/전송하기 위한 이진 포맷             |

* Arrow IPC는 데이터를 파일로 저장하거나 전송할 때 사용하는 포맷
* Flight에서도 내부적으로 IPC 포맷 사용

### Python IPC 예제

```python
import pyarrow as pa
import pyarrow.ipc as ipc

batch = pa.record_batch([pa.array([1, 2, 3])], names=["col"])
sink = pa.BufferOutputStream()

with ipc.new_stream(sink, batch.schema) as writer:
    writer.write_batch(batch)

buf = sink.getvalue()
reader = ipc.open_stream(buf)
for b in reader:
    print(b)
```

## 마무리 요약

* Apache Arrow: 고성능 컬럼 기반 메모리 포맷
* Arrow Flight: 네트워크 전송용 gRPC 기반 고속 프로토콜
* Flight SQL: Flight 위에서 SQL 쿼리를 실행할 수 있도록 확장한 사양
* ADBC: 다양한 DB에 SQL을 실행하고 Arrow 포맷으로 데이터를 주고받는 표준 인터페이스
* IPC (in Arrow): Arrow 데이터를 파일이나 네트워크로 주고받기 위한 바이너리 포맷
